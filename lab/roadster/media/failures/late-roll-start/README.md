# r4 · 先升高，后滚转

- `trajectory.json`：原记录逐帧姿态、位置、力与接触，无插值、无重模拟。
- `config.json`：源回放的世界配置。
- `provenance.json`：原文件、源码和帧哈希，版本与失败时刻。
- `caption.md`：可用的简短说明。
- `clean.mp4`：无说明文字的竖屏版。
- `annotated.mp4`：同一视频加文字与状态读数。

米级启动门槛限制了策略空间；尚未完成一周滚转便车身触地。

此素材是本项目的数值试验，不是Tesla实拍，也不是实车事故。画面外壳与接触几何不同；烟雾只示意喷口方向和相对强度。

已导出：1080×1920，30 fps，H.264，时长 3.233 秒，无音轨。两版共用 97 张底图；最后为30fps封装补齐 0.033 秒，不是新增物理运动。
