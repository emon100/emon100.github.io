# 可复现的仿真与策略搜索

这是 6DoF 教学仿真，不是 Tesla 数字孪生。尺寸、质量、喷力、气量、风机、24 m 等价场地射程和20 m 高处起点都是 `config.json` 的明示假设。障碍分别配置位置、长宽高和朝向；五车车列不能用车长相加。

真实执行 CEM 参数搜索：每个候选反馈控制器都经过刚体积分、有限喷力与力矩分配、耗气和碰撞判定。优化的是控制增益及参考轨迹时序；参考轨迹不是输出飞行轨迹。`results.json` 保存每代全部候选分数、参数、早/中/末真实轨迹、独立样本评估与姿态/高度成功网格。三个任务分别优化策略；独立评估改变质量、80%/100% 推力上限和示例射程，不能称为一个已证明的全角度控制器。

```sh
PYTHON=/Users/emon100/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3
"$PYTHON" simulation/test_core.py
"$PYTHON" simulation/train.py

```

风机与喷口全部系数是假设。喷气主模型假设前70%气量可调压，后30%会降压和冷却；结果另保留无调压降压的敏感性失败，不能把固定比冲或调压能力当成已验证硬件。

需要已有 NumPy。本次使用 Codex 随附 Python，未安装依赖。原始 30 m 失败与首次域外评估保存在 `results-first-pass.json` 和 `results-envelope-validation.json`。固定 seed 可重跑；改变 `dt`、配置或参数需重新训练/评估。实际训练时长写入结果。

风机近表面吸附取决于间隙、朝向和漏气；压力功与排气动能共享功率预算。远离表面只有固定机身尾向排气的 EDF 反作用，其上限由功率和叶轮盘面积估计。它不是任意方向的自由升力源。喷口为假设的双向六轴等效分配器，并分解为 18 个虚拟执行器以核对合力、力偶和耗气，不是 Tesla 已确认布局。

Kickflip 验收跟踪实际车身上轴在世界 YZ 平面的展开角，且纵轴偏离世界 X 不超过15°；只验证指定纵轴翻转任务，不能用机身角速度积分证明任意三维回转。

限制：均匀刚体、简化气体比冲与惯量、理想观测、无风扰/地效CFD/真实压力罐降压过程；障碍采用保守旋转包围盒。接触按姿态、质心和四个底角接地点的速度容差判定；“成功”仅指接触瞬间达标，不求轮胎/悬架冲击或着地后稳定。成功网格只覆盖采样初态；低高度失败不能全部当成物理不可达，成功也不保证任意姿态可行。
