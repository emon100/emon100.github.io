# Codex 对 Kimi 原稿的复核

独立原稿为 `kimi.raw.mjs`，SHA-256 `2875e6f3872f7eef0e0f83e7bc78f6e4f54adfc689be1e18199c394015edb510`，未修改。派生结果为 `site/dist/figures/kimi-codex.mjs`。保留 Kimi 的车身零件、等轴投影、面着色、描边和台座风格。

| 原稿问题 | 派生版修改 |
|---|---|
| `.k3iso .iso` 要求一个不存在的内层主题根 | 改成根选择器 `.k3iso`，补齐包装类，保留浅色主题和 SVG 导出入口；按浏览器反馈提高深色四级面的亮度 |
| 场景 2 是水平倒悬，原片 02 显示过垂直斜坡 | 改成下部弧面接直坡。示意坡角 115°，并非图像标定结果 |
| 轮胎零点代替轮心导致曲面接触误差 | 两轮心沿偏移曲线求解固定轴距，支撑姿态跟随同一坡面 |
| 场景 4 通过俯仰半周回正 | 改为绕车身纵轴滚转，保持车头方向 |
| 起跳、越车、倒转之间会跳位置，背景车也突然变形 | 1–5、6–10 各自连续；背景统一为四辆小车和中央 Semi，并排朝向垂直于飞行方向 |
| 场景 8 默认中点只是侧翻 | 7 末 117°、8 中点 180°、8 末 243°、9 末 360°，姿态连续 |
| 垫面有厚度，但车轮从 z=0 起落 | 四轮接触垫顶；回正下降延后到车身越过 Semi 后 |
| 无单位高度、间隙小数容易造成实测印象 | 删去这些数字，只显示示意姿态与阶段；所有读数保留“示意，非实测” |

已运行 `node research/kimi/kimi-codex.selfcheck.mjs`，10 项通过。坡道组 78 个实体、车列组 79 个实体，不含台座绘制层。检查了 1,010 个刚体姿态、8 处场景连接、四轮起落接触、五车方向、110 帧 SVG、深浅主题选择器和 mount/destroy 接口。凸多面体车身与环境检查的最大穿入为 0.048 示意单位，低于曲面离散容差 0.08；不能称为严格零穿模。
